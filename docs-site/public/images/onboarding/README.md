# Onboarding flow screenshots

Built desktop app at 1024px with fictional tenant and sign-in results. No Microsoft sign-in or registration writes are made. Generated by `node scripts/onboarding-shots.mjs`. Choice screens use a 1024 by 768 viewport and assert that Continue is visible without scrolling, including expanded cards. Card details scroll inside their card. The exact permissions disclosure and other tall screens include all content for review.
